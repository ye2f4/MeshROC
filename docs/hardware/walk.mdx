**MeshROC Walk** 是 MeshROC 的主力产品，面向户外徒步与应急单兵通信的手持终端。

## 核心规格

| 项目 | 规格 |
| --- | --- |
| 主控 | ESP32-S3 |
| 显示屏 | ST7789 高清屏幕 |
| 输入 | 实体 7 键键盘（PCF8574 IO 扩展） |
| 传感器 | AHT20 温湿度 + 电池 ADC 检测 |
| 工作频段 | 470–490MHz |
| 网络角色 | `CLIENT_MUTE`（静默终端） |
| 供电 | 内置锂电池 |

## 设计定位

Walk 的核心设计目标是**独立可用**——不依赖手机也能完成收发消息的完整流程。

在应急场景中，手机可能没电、可能损坏、可能因低温关机。一台自带屏幕与键盘的终端，在这些情况下仍然可用。

## 实体键盘

采用 7 键实体键盘，通过 PCF8574 进行 IO 扩展，配合**键盘中断唤醒系统**实现低功耗待机。

选择实体键盘而非触摸屏的原因：

- 户外可**戴手套操作**；
- 低温环境下不受电容触摸失灵影响；
- 盲操作可行，无需持续注视屏幕；
- 功耗与成本更低。

## 显示与抗干扰

采用 ST7789 高清屏幕，通过 SPI 接口驱动。

:::note 自研抗干扰驱动

原版 Meshtastic 在自研 PCB 上存在一个典型问题：**大功率 LoRa 发射时会干扰 SPI 屏幕显示**，表现为闪烁、花屏或数据异常。

MeshROC 针对此实现了 SPI 屏幕抗干扰驱动，同时在 PCB 布局上规避了 USB 引脚冲突问题。这是 MeshROC 固件必须搭配使用的原因之一——刷入原版固件会重新出现该问题。

:::

## 传感与电量监测

- **AHT20 温湿度传感器**：采集环境温湿度，可作为遥测数据在网络中共享；
- **电池 ADC 检测**：实时监测电量。

ADC 采样同样会受到大功率发射的干扰，MeshROC 固件内置了 **ADC 防抖滤波**，避免发射瞬间产生的电压跌落被误判为低电量。

## 网络角色

Walk 默认配置为 `CLIENT_MUTE` 静默终端：

```ini
role = CLIENT_MUTE
```

这意味着它只发送自己产生的消息，不转发他人消息。带来两个好处：

1. **续航显著改善**——不为他人消息消耗电量；
2. **网络容量提升**——减少参与转发的节点数，降低信道拥塞。

网络的转发工作由 [Backbone](/docs/hardware/backbone) 与 [Gateway](/docs/hardware/gateway) 骨干节点承担。

## 使用建议

:::danger

**上电前务必连接天线。**

:::

- 户外使用时注意天线朝向，垂直放置通常效果最佳；
- 人体会明显吸收信号，发送重要消息时可将设备举高、远离身体；
- 低温会显著降低锂电池容量，冬季户外建议贴身携带备用电源。
