**MeshROC Backbone** 是山顶太阳能骨干节点，承担网络中的核心中继任务。它是扩大 Mesh 网络覆盖范围最有效的手段。

## 核心规格

| 项目 | 规格 |
| --- | --- |
| 主控 | ESP32-S3 |
| 最大发射功率 | 30dBm |
| 供电方案 | CN3791 太阳能充电 + 锂电池 |
| 工作频段 | 470–490MHz |
| 网络角色 | `BACKBONE`（参与转发） |
| 部署方式 | 山地制高点长期无人值守 |

## 设计定位

Backbone 解决的是「覆盖」问题。手持终端的单跳距离有限，而部署在制高点的骨干节点可以：

- 与其他骨干建立**准视距长链路**，实现数十公里级的跨越；
- 为周边大范围内的终端提供接入点；
- 通过多跳接力，把分散的局部网络连成一张整网。

## 大功率发射

Backbone 支持最高 30dBm 发射功率，用于骨干之间的长距离链路。

:::danger 合规与安全

- 请确认 30dBm 功率的使用符合当地无线电管理规定；
- **上电前务必连接天线**，否则可能损坏射频芯片。

:::

大功率发射会带来射频干扰问题——原版 Meshtastic 在此场景下存在屏幕闪烁、ADC 采样异常等缺陷。MeshROC 固件内置了抗射频干扰处理与 ADC 防抖滤波，专门解决该问题。

## 太阳能供电

采用 CN3791 太阳能充电管理方案，配合固件的智能电源策略实现长期自主运行。

### 容量规划

太阳能系统的设计核心是**按最差条件规划**，而非平均条件：

- 按冬季日照与连续阴雨天估算，太阳能板功率建议留出 2–3 倍裕量；
- 电池容量应能支撑连续数个阴雨天的运行；
- 注意锂电池的**低温特性**——冬季山区温度可能低于电池的正常工作范围，必要时需考虑保温或选用低温型电池。

### 面板安装

- 朝南倾斜安装，倾角接近当地纬度；
- 避开树荫与建筑遮挡，注意不同季节太阳高度角的变化；
- 定期检查面板表面积灰情况。

### 智能电源策略

MeshROC 固件会根据当前电量与光照情况动态调整节点的占空比。在电量偏低时自动降低活跃度，优先保证节点不掉线，而非维持满负荷转发。

## 部署建议

- **选址优先于一切**：一个视野开阔的位置，胜过任何参数调优；
- **相邻骨干保持准视距**：这是长链路成功的前提；
- **避免区域内堆叠过多骨干**：否则会退化回洪泛，失去分层路由的意义；
- **天线优先投资**：抬高天线、提升增益的收益，通常大于提高发射功率。
