**MeshROC Gateway** 是面向城市环境的 POE 固定基站，适合楼宇长期部署与内网数据转发。

## 核心规格

| 项目 | 规格 |
| --- | --- |
| 主控 | ESP32-S3 |
| 有线网络 | W5500 以太网控制器 |
| 供电方案 | POE 供电 |
| 工作频段 | 470–490MHz |
| 网络角色 | `BACKBONE`（参与转发） |
| 运行模式 | 7×24 小时长期在线 |

## 设计定位

Gateway 解决的是城市环境下的两个问题：

1. **复杂遮挡**：城市建筑对 LoRa 信号的阻挡严重，需要在楼顶等高处设置固定锚点；
2. **网络接入**：通过有线网口接入内网，实现数据转发与远程管理。

## POE 供电优势

单根网线同时完成供电与数据传输，这在楼宇部署中意义重大：

- **布线简洁**：无需在楼顶单独引电源，省去大量施工成本；
- **供电稳定**：不受日照条件影响，可保证真正的 7×24 小时运行；
- **便于维护**：可通过交换机远程断电重启。

相比太阳能方案，POE 在有市电条件的城市环境中是更可靠的选择。

## W5500 有线网络

采用 W5500 硬件 TCP/IP 协议栈芯片，相比纯软件方案更稳定、占用主控资源更少。

有线网络能力带来的应用可能：

- 将 Mesh 网络的数据转发至内网服务器进行存储与分析；
- 远程配置与固件管理，无需现场操作；
- 作为多个地理位置分散的 Mesh 子网之间的桥接。

## 部署建议

- **架设高度优先**：楼顶天面优于窗边，天线越高覆盖越好；
- **避开强干扰源**：远离大功率发射设备与金属结构反射面；
- **注意防水防雷**：室外部署需做好天线接头防水，高处安装应考虑防雷措施；
- **网线规格**：室外走线需使用室外级网线，注意 POE 供电的距离限制。

## 与 Backbone 的选择

| 场景 | 推荐 |
| --- | --- |
| 山区、无市电 | Backbone（太阳能） |
| 城市楼宇、有市电与网络 | Gateway（POE） |
| 需要接入内网做数据转发 | Gateway |
| 需要 30dBm 大功率长链路 | Backbone |

两者在网络中都担任 `BACKBONE` 角色，可以混合部署，共同构成骨干层。
