**MeshROC China Group** 是国内首个基于 Meshtastic、深度优化本土化的 LoRa Mesh 开源社群。

## 我们关注什么

### 北京山地远距离实测

社区持续在北京周边山区进行实地测试。山地非视距（NLOS）环境是国内应急通信最典型也最困难的场景，实测数据直接指导固件的路由算法与射频参数调优。

### 国产自研硬件迭代

四条产品线的硬件设计在社区中公开迭代，全部立创开源、星火计划入库。欢迎参与原理图评审、元器件选型讨论与 PCB 布局改进。

### 固件路由算法优化

分层骨干路由、自适应跳数、信噪比择优路径等机制都源自社区的实测反馈与讨论。

### 应急通信技术交流

围绕断网场景下的通信保障展开讨论，包括部署方案、供电设计、天线选型与实战经验。

### 开源资料共建共享

固件、PCB 工程、3D 模型与文档全部开源共享。

## 如何参与

### 分享实测数据

这是当前**最需要**的贡献。任何真实环境下的测试数据都很有价值，建议包含：

- 测试地点的地形描述（山地 / 城区 / 开阔地）
- 收发两端的设备型号、天线类型与架设高度
- 实测距离与 SNR / RSSI 数值
- 使用的调制参数预设

### 参与开发

固件、硬件与文档均欢迎贡献，详见[贡献指南](/docs/contributing)与[开发者指南](/docs/developers)。

### 帮助新手

社区中不断有新成员加入。解答一个新手的疑问，往往比写一行代码更有价值。

## 社区准则

- 保持友善与专业，耐心对待不同经验水平的参与者；
- 讨论技术问题时尽量提供可复现的信息（配置、日志、实测数据）；
- **遵守当地无线电管理规定**，不鼓励、不协助任何违规使用行为。

## 合规提醒

:::caution

MeshROC 使用 470–490MHz 免授权频段，正常使用无需执照。但请注意：

- 发射功率、占空比等仍需符合相关规定；
- 大功率部署（如 Backbone 的 30dBm）前请确认合规性；
- 不要将设备配置到未经许可的频段。

:::
