LoRa 配置决定了设备的无线电行为，是影响通信能否成功的最关键配置组。

:::caution

**同一网络内所有节点的频段、调制预设与频率槽位必须完全一致**，否则无法互相通信。修改这些参数时请确保全网同步变更。

:::

## 配置项一览

| 配置项 | 说明 | 默认值 |
| --- | --- | --- |
| `region` | 频段区域 | `CN`（470–490MHz） |
| `modem_preset` | 调制预设 | `LONG_FAST` |
| `tx_power` | 发射功率（dBm） | 按型号而定 |
| `hop_limit` | 最大跳数 | `3` |
| `tx_enabled` | 是否允许发射 | `true` |

## region —— 频段区域

设置为 `CN` 时使用 470–490MHz，这是国内的免授权频段。

该配置同时决定了允许的最大发射功率与占空比限制。请勿为了「性能」而设置为其他地区的频段——那可能违反当地无线电管理规定。

## modem_preset —— 调制预设

预设是扩频因子、带宽与编码率的组合，直接决定传输距离与速率的权衡：

| 预设 | 扩频因子 | 带宽 | 适用场景 |
| --- | --- | --- | --- |
| `SHORT_FAST` | SF7 | 250 kHz | 密集城区、节点多、距离近 |
| `MEDIUM_SLOW` | SF10 | 250 kHz | 均衡场景 |
| `LONG_FAST` | SF11 | 250 kHz | **默认**，兼顾距离与吞吐 |
| `LONG_SLOW` | SF12 | 125 kHz | 骨干长链路、极限距离 |

:::tip 不要盲目追求最远距离

`LONG_SLOW` 虽然距离最远，但空中时间成倍增长，会大幅降低网络容量。在节点较多的网络中，使用 `LONG_FAST` 配合[分层骨干路由](/docs/overview/mesh-alg)通常效果更好。

:::

## tx_power —— 发射功率

发射功率以 dBm 为单位。MeshROC Backbone 支持最高 30dBm，用于山顶骨干的长距离链路。

MeshROC 固件内置**动态功率调节**：当与邻居节点的信噪比明显富余时会自动降低功率，以减少干扰、降低功耗，并减轻大功率发射对屏幕与 ADC 采样的影响。

:::danger

请确认你的发射功率设置符合当地法规。同时再次提醒：**未连接天线时不要发射**。

:::

## hop_limit —— 最大跳数

数据包每被转发一次，跳数减一，归零后不再转发。

默认值 `3` 适用于大多数场景。MeshROC 的骨干节点支持**自适应跳数**，会根据观测到的网络规模动态调整，通常无需手动干预。

过大的跳数会让消息在网络中存活过久，产生无谓的转发流量；过小则会导致边缘节点收不到消息。

## tx_enabled —— 发射开关

设为 `false` 时设备只接收不发射，可用于监听或调试。

:::caution

在没有天线的情况下测试设备时，应将此项设为 `false` 以避免损坏射频芯片。

:::
