MeshROC 基于 Meshtastic 协议生态构建，但**不是简单的二次开发**。本文说明两者的确切兼容边界。

## 完全兼容的部分

所有 MeshROC 设备可与全球标准 Meshtastic 设备互相通信，包括：

- 文本消息收发
- 位置信息共享
- 节点信息（NodeInfo）交换
- 遥测与传感器数据
- 频道与加密密钥体系

只要**调制参数（频段、扩频因子、带宽、编码率）与频道配置一致**，MeshROC 设备与标准 Meshtastic 设备即可加入同一网络并正常互通。

## MeshROC 独有增强

以下能力是 MeshROC 在原版基础上新增的。它们均为**本地策略或驱动层优化，不修改协议帧格式**，因此在混合组网时不会破坏互通性——标准设备按原有规则工作，MeshROC 设备按优化策略工作。

| 增强项 | 说明 | 混合组网影响 |
| --- | --- | --- |
| 分层骨干路由 | 限定骨干节点转发，终端静默 | 无，标准设备仍按洪泛工作 |
| 山地 NLOS 优化 | 链路预算紧张时自适应调整参数 | 无 |
| 太阳能智能电源管理 | 按光照与电量动态调整占空比 | 无 |
| 470MHz 本土化适配 | 国内免费频段合规参数 | 需双方使用相同频段 |
| 自研 ESP32-S3 外设驱动 | 屏幕、键盘、GNSS、温湿度适配 | 无（纯本机） |
| 抗射频干扰系统 | 抑制大功率发射对屏幕/ADC 的干扰 | 无（纯本机） |
| 低功耗休眠防丢包 | 修复休眠期间丢包与发送中断 | 无 |
| 自定义报文智能解析 | 扩展报文的解析与自动控制 | 标准设备忽略未知报文 |

## 混合组网的注意事项

在同一网络中同时部署 MeshROC 与标准 Meshtastic 设备时，请注意：

1. **调制参数必须全网一致**。这是能否通信的前提，与设备品牌无关。
2. **骨干角色只对 MeshROC 设备生效**。标准 Meshtastic 设备无法被配置为「静默终端」，它们仍会参与洪泛转发。若网络中标准设备占比很高，分层骨干带来的容量收益会被稀释。
3. **加密密钥需一致**。频道密钥不同的设备无法解析彼此的消息内容。

## 版本与协议

MeshROC 固件跟进上游 Meshtastic 的协议版本演进。当上游发生**不向后兼容的协议变更**时，我们会在发布说明中明确标注需要同步升级的最低版本。

建议在同一网络内尽量保持固件版本相近，以避免因协议差异导致的兼容问题。
