MeshROC 是一个由社区驱动的开源项目：固件源自 GPL-3.0 的 Meshtastic，沿用 **GPL-3.0**；硬件以开源硬件形式在立创开源平台入库（星火计划）；文档与官网以 **MIT License** 开源。我们欢迎任何形式的贡献。

## 可以贡献什么

### 实地测试数据

这是当前**最需要**的贡献类型。LoRa 的实际表现高度依赖地形，任何真实环境下的测试数据都很有价值：

- 测试地点的地形描述（山地 / 城区 / 开阔地）
- 收发两端的设备型号、天线类型与架设高度
- 实测距离、SNR / RSSI 数值
- 使用的调制参数预设

山地非视距场景的数据尤其宝贵，它直接指导路由算法与射频参数的调优方向。

### 固件开发

固件基于 Meshtastic 上游分支，重点优化方向包括：

- 分层骨干路由算法
- 电源管理与休眠策略
- 自研 PCB 的外设驱动适配
- 抗射频干扰处理

### 硬件迭代

四条产品线的 PCB 工程均已开源。欢迎提交原理图改进建议、元器件选型优化、外壳结构改良等。

### 文档完善

如果你在使用过程中发现文档缺失、描述不清或与实际不符，欢迎直接提交修改。文档改进对新用户的帮助往往超出想象。

## 贡献流程

1. 在提交较大改动前，建议先通过 Issue 或社区讨论说明你的思路，避免重复劳动；
2. Fork 仓库，在独立分支上开发；
3. 提交 Pull Request，并在描述中说明**改动动机**与**验证方式**；
4. 涉及射频或路由行为的改动，请尽量附上实测数据。

## 代码约定

- 固件遵循上游 Meshtastic 的代码风格；
- 与上游有差异的改动请添加注释说明原因，便于后续合并上游更新；
- 涉及协议层的改动需格外谨慎，**任何破坏与标准 Meshtastic 互通性的改动都不会被接受**。

## 行为准则

请保持友善与专业。我们欢迎不同经验水平的参与者，请耐心对待新手提问。
