## MeshROC 如何工作

MeshROC 通过 LoRa 无线电建立 Mesh 网络。你的手机或电脑通过蓝牙、WiFi 或 USB 连接到设备，即可在完全没有互联网与手机信号的环境中与他人通信。

网络中的骨干节点会自动转发消息，因此实际通信距离远超单台设备的直连范围。

## 选择你的硬件

在开始之前，需要先确定你使用的设备型号。MeshROC 提供四条自研产品线，全部立创开源、星火计划入库。

### MeshROC Walk —— 手持终端（推荐新手）

主力产品，适合户外徒步与应急单兵通信。

- ESP32-S3 主控
- ST7789 高清屏幕
- 实体 7 键键盘（PCF8574 IO 扩展）
- AHT20 温湿度传感 + 电池 ADC 检测

### MeshROC Backbone —— 山顶太阳能骨干节点

用于扩大网络覆盖的核心中继。

- 大功率 30dBm LoRa 远距离中继
- CN3791 太阳能自主供电
- 适合山地制高点长期无人值守部署

### MeshROC Gateway —— POE 城市基站

- ESP32-S3 + W5500 有线网口
- POE 供电，7×24 小时稳定运行
- 适合城市楼宇固定节点与内网数据转发

### MeshROC Sensor —— 低功耗传感终端

- ESP32-C3 超低功耗方案
- 适合野外环境监测、追踪与数据采集

:::info

如果你只是想先体验 MeshROC，建议从 **MeshROC Walk** 开始。两台 Walk 即可组成一个可用的网络。想要扩大覆盖范围时，再增设 Backbone 骨干节点。

:::

各型号的详细参数请参阅[硬件文档](/docs/hardware-docs)。

## 检查数据线

:::danger 停！先别急着上电

**在未连接天线的情况下，绝对不要给设备上电发射**，否则可能永久损坏射频芯片。上电前请务必确认天线已正确安装。

:::

部分 USB 线只能充电、不能传输数据。在连接设备之前，请先确认你的数据线支持数据传输——可以用它连接手机并尝试传输文件来验证。这是烧录失败最常见的原因之一。

## 安装串口驱动

MeshROC 的四条产品线均基于 ESP32 系列芯片（ESP32-S3 / ESP32-C3），通常需要安装 USB 转串口驱动才能被电脑识别。
