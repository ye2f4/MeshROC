本节面向希望参与 MeshROC 固件或硬件开发的贡献者。

## 项目构成

MeshROC 由三部分组成，按各自适用的许可证开源：

| 部分 | 许可证 | 说明 |
| --- | --- | --- |
| 固件 | **GPL-3.0** | 基于 Meshtastic 上游分支（GPL-3.0）的优化实现 |
| 硬件 | 开源硬件（立创开源 / 星火计划） | 四条产品线的 PCB 工程与原理图 |
| 文档 | **MIT** | 本文档站点 |

## 固件开发

### 构建环境

固件基于 PlatformIO 构建。基本流程：

```bash
# 安装 PlatformIO CLI
pip install platformio

# 编译指定型号
pio run -e meshroc-walk

# 编译并烧录
pio run -e meshroc-walk -t upload
```

不同型号对应不同的构建环境（environment），请注意 ESP32-S3 与 ESP32-C3 的区别。

### 主要优化模块

MeshROC 相对上游的改动集中在以下几个方面：

**路由层**
- 分层骨干路由：角色区分与转发策略
- 自适应跳数：根据网络规模动态调整
- 信噪比择优：将退避时长与链路质量挂钩

**电源管理**
- 休眠防丢包：确保发送完整结束后再休眠
- 太阳能智能策略：按电量与光照调整占空比

**射频层**
- 470–490MHz 国内频段适配
- 动态功率调节
- LBT/CAD 防碰撞增强

**外设驱动**
- SPI 屏幕抗干扰驱动（规避 USB 引脚冲突）
- 键盘中断唤醒（PCF8574）
- GNSS 定位适配
- AHT20 温湿度与电池 ADC 防抖滤波

### 与上游同步

MeshROC 持续跟进 Meshtastic 上游的协议演进。开发时请注意：

:::danger 协议兼容性红线

**任何破坏与标准 Meshtastic 互通性的改动都不会被接受。**

MeshROC 的所有优化都在策略层与驱动层实现，**不修改协议帧格式**。这是保证混合组网可用的前提。

:::

- 与上游有差异的改动请添加注释说明原因，便于后续合并上游更新；
- 涉及协议层的改动需格外谨慎，应先在社区讨论。

## 硬件开发

四条产品线的 PCB 工程均已在立创开源平台入库（星火计划）。

欢迎的贡献方向：

- 原理图改进建议
- 元器件选型优化（成本、供货、性能）
- PCB 布局改良，特别是射频部分的干扰抑制
- 3D 外壳结构设计

:::tip 射频布局提示

大功率发射对数字电路的干扰是自研 LoRa 板卡最常见的坑。已知问题包括干扰 SPI 屏幕显示、影响 ADC 采样精度。

MeshROC 现有设计通过 PCB 布局与固件滤波共同缓解该问题。提交布局改动时请特别关注这部分。

:::

## 测试与验证

涉及射频或路由行为的改动，**请尽量附上实测数据**：

- 测试地形与环境描述
- 设备型号、天线与架设高度
- 实测距离与 SNR / RSSI
- 使用的调制参数

山地非视距场景的数据尤其有价值。
